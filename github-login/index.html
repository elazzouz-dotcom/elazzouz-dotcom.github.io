تسجيل دخول GitHub — غير مفعّل

الموقع لا يملك حاليًا OAuth Client ID أو خادم Callback، لذلك لا يوجد زر دخول فعلي ولا يتم تسجيل دخول حساب GitHub من هذه الصفحة.

إعداد OAuth App ↗صفحة التكاملات

ما يلزم لتفعيل تسجيل الدخول

  1. إنشاء OAuth App داخل GitHub Developer Settings.
  2. وضع Client ID في إعدادات الواجهة، مع إبقاء Client Secret على خادم خلفي فقط.
  3. إنشاء Callback على Cloudflare Worker أو n8n أو خادم Node.js باستخدام HTTPS.
  4. تخزين access token بشكل مشفر وعدم إرساله إلى GitHub Pages أو localStorage.
https://YOUR-BACKEND.example.com/oauth/github/callback

لا يمكن تنفيذ تبادل Client Secret بأمان داخل موقع GitHub Pages ثابت؛ لذلك لم أضع زرًا وهميًا أو كودًا يوحي بأن الحساب مسجّل.
