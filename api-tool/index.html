Agent token

Use an existing VTAI Agent Token or register one. The token stays in this page's memory and is never saved to browser storage. OAuth tokens are not REST credentials.

Register once and reuse the returned identity. Keep your token private. Browser requests may fail if the API does not permit cross-origin requests (CORS).

Existing reports

Look up an indicator

Lookups retrieve existing intelligence; they do not explicitly start a new analysis. Each lookup uses query quota. A missing report is unknown evidence, not a safe verdict.

File analysis

Submit a file and recover its receipt

Files are shared with VirusTotal and its security community and partners. Do not submit private documents, internal code, credentials, or personal data without permission. Maximum size: 32,000,000 bytes. The file is sent as raw bytes; no automatic retry is made.

The file's SHA-256 will be calculated before submission.

Ruby · VirusTotal API

Download an hourly file-feed batch

This endpoint requires a File feeds license and an API key. Enter the batch hour in UTC as YYYYMMDDhh; batches are available up to 7 days back, with a 2-hour delay on the newest batch. A successful request redirects to a .tar.bz2 archive containing 60 minute-by-minute feeds. After extraction, each UTF-8 text file contains one file-object JSON record per line, including feed context such as download_url and, when available, submitter. This example follows the redirect and saves the archive locally.

Set VT_API_KEY in your environment before running this Ruby script. Keep the key secret. This API key is separate from the VTAI Agent Token used elsewhere on this page.

Run it with a UTC batch hour, for example ruby hourly_feed.rb YYYYMMDDhh. A successful request redirects to a .tar.bz2 archive containing 60 UTF-8 text files, one per minute. Each line is a file-object JSON record; records may include download_url and a non-identifying, lossy-ciphered submitter context field. The submitter field is not present on every record. A File feeds license is required.

require 'uri'
require 'net/http'

api_key = ENV.fetch('VT_API_KEY')
time = ARGV.fetch(0) { abort 'Usage: ruby hourly_feed.rb YYYYMMDDhh' }
abort 'Time must use YYYYMMDDhh format.' unless /\A\d{10}\z/.match?(time)

url = URI("https://www.virustotal.com/api/v3/feeds/files/hourly/#{time}")
request = Net::HTTP::Get.new(url)
request['accept'] = 'application/json'
request['x-apikey'] = api_key

response = Net::HTTP.start(url.host, url.port, use_ssl: true) do |http|
  http.request(request)
end

if response.is_a?(Net::HTTPRedirection)
  location = response['location'] or abort 'Redirect did not include a download URL.'
  download_url = URI.join(url.to_s, location)
  abort 'Refusing a non-HTTPS download URL.' unless download_url.is_a?(URI::HTTPS)

  download = Net::HTTP.start(download_url.host, download_url.port, use_ssl: true) do |http|
    http.get(download_url.request_uri)
  end
  abort "Download failed: HTTP #{download.code}" unless download.is_a?(Net::HTTPSuccess)

  File.binwrite("hourly-feed-#{time}.tar.bz2", download.body)
  puts "Saved hourly-feed-#{time}.tar.bz2"
else
  abort "Feed request failed: HTTP #{response.code} #{response.message}\n#{response.body}"
end

After the download, extract the archive locally with tar -xjf hourly-feed-YYYYMMDDhh.tar.bz2, replacing the time placeholder with the batch hour you requested. Treat downloaded samples and metadata as untrusted, and handle them in accordance with your organization’s security and data-handling policies.
