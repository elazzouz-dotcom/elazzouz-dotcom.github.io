Try copy, cut, or paste on the editable area or text field. Browsers may restrict or omit event data.

    Important security limits

    • A script-created clipboard event is not a trusted OS paste and cannot grant clipboard access.
    • Reading the system clipboard requires a user action and browser permission; it may be unavailable.
    • Pasted text is treated as plain text in this tool. Do not paste secrets into a shared or untrusted device.

    Format check

    The event log reports available MIME types and whether file items exist. It does not export, upload, or retain file contents.
