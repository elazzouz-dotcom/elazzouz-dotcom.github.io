OneCompiler AI → GitHub Pages

بعد تسجيل الدخول إلى GitHub من Hosting Studio، يستطيع OneCompiler AI إرسال الملفات المعدلة إلى GitHub وإنشاء Commit مباشرةً عبر Cloudflare Worker، من دون نسخ الملفات يدويًا أو وضع Access Token داخل المشروع.

الإعداد مرة واحدة

  1. افتح Hosting Studio واضغط «ربط حساب GitHub» وأكمل Device Flow.
  2. اترك Hosting Studio مفتوحًا في المتصفح نفسه؛ Worker يعتمد على الجلسة المشتركة.
  3. افتح مشروع OneCompiler.
  4. أضف ملف الجسر الجاهز إلى المشروع:
<script src="https://elazzouz-dotcom.github.io/onecompiler-publish-bridge.js"></script>

ممنوع: لا تضف CLIENT_SECRET أو gho_... أو أي Access Token إلى ملفات OneCompiler.

عقد ثابت لا يتغير

الجسر يثبت Worker والوجهة داخليًا؛ لا يستطيع كود OneCompiler تغييرها. Worker هو https://github-oauth-proxy.elazzouz4.workers.dev، والمالك elazzouz-dotcom، والمستودع elazzouz-dotcom.github.io، والفرع main. يمكن تغيير رسالة الـ Commit والملفات المعدلة فقط.

الاستدعاء الأساسي

بعد انتهاء OneCompiler AI من التعديل والتحقق، اجمع الملفات المعدلة فقط ثم نفّذ:

await OneCompilerGitHub.publishToGitHub({
  owner: 'elazzouz-dotcom',
  repo: 'elazzouz-dotcom.github.io',
  branch: 'main',
  message: 'Update site from OneCompiler AI',
  files: {
    'index.html': document.documentElement.outerHTML,
    'theme.css': updatedThemeCss,
  },
});

استخدم مسارات نسبية وقيمًا نصية للملفات. لا تستخدم مسارًا يبدأ بـ / أو يحتوي على ...

Prompt جاهز لـ OneCompiler AI

أضف ملف الجسر من https://elazzouz-dotcom.github.io/onecompiler-publish-bridge.js باستخدام script tag. بعد كل تعديل ناجح، اجمع الملفات النهائية المعدلة في كائن files، ثم استدعِ await OneCompilerGitHub.publishToGitHub({ owner: 'elazzouz-dotcom', repo: 'elazzouz-dotcom.github.io', branch: 'main', message: 'Update site from OneCompiler AI', files }). اعرض نتيجة الـ Commit للمستخدم. لا تنشئ Access Token ولا تضع أي سر داخل الكود، ولا تستدعِ النشر قبل اكتمال التعديل والتحقق من الملفات.

زر نشر اختياري

OneCompilerGitHub.createPublishButton({
  button: '#publish-button',
  message: 'Publish reviewed OneCompiler changes',
  getFiles: async () => ({
    'index.html': document.documentElement.outerHTML,
  }),
});
