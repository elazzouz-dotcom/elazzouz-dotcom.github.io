# المساعد الذكي السحابي

هذه الدالة اختيارية وتستخدم فقط عند تسجيل دخول المستخدم. تحفظ مفتاح مزود الذكاء الاصطناعي في أسرار Supabase، ولا تضعه داخل ملفات الموقع العامة.

## الأسرار المطلوبة

```bash
supabase secrets set OPENAI_API_KEY="مفتاحك" OPENAI_MODEL="معرّف النموذج الذي يوفره مزودك"
```

لا تستخدم اسم نموذج عشوائيًا؛ اختر معرّفًا مدعومًا من حساب مزود الذكاء الاصطناعي.

## النشر

```bash
supabase functions deploy ai-assistant
```

بعد النشر، سيستخدم الموقع الدالة تلقائيًا. وإذا لم تكن الدالة منشورة أو لم يتم إعداد الأسرار، سيستمر التحليل المحلي داخل المتصفح بدل إظهار خطأ للمستخدم.

## حدود الاستخدام

الدالة تحلل بيانات السجل والتنبيهات التي يرسلها الموقع فقط. لا تدخل إلى TikTok، ولا تقرأ الشاشة، ولا تضغط الأزرار، ولا تجمع الصناديق أو العملات آليًا.
