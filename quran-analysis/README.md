# التحليل القرآني الاستكشافي

تحتوي الصفحة على معاينة متصفح محلية للجذور الرقمية وحساب الجمل واختبار مونت كارلو. التقرير القابل لإعادة الإنتاج موجود في `analyzer.py`.

## التشغيل العلمي

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r quran-analysis/requirements.txt
python - <<'PY'
from analyzer import ScientificQuranAnalyzer
# مرّر قائمة السور بالشكل [(1, "الفاتحة", 7), ...]
# report = ScientificQuranAnalyzer(dataset).build_report(B=200_000, seed=12345)
PY
```

التحليل يصحح الوصول إلى عمود النوع باستخدام `self.df["type"]`، ويسجل `seed=12345` و`PCG64` وإصدارات NumPy وSciPy وpandas. ويطبق محاكاة مونت كارلو على الجذر المركب، جذر رقم السورة، جذر عدد الآيات، وجذر حساب الجمل، بدل عرض إحصاء كاي تربيع منفردًا لحساب الجمل.

قواعد التطبيع موثقة داخل التقرير: الهمزات إلى ألف، التاء المربوطة إلى هاء، الهمزة على الواو إلى واو، والألف المقصورة إلى ياء. الأحرف غير الموجودة في الخريطة لا تضيف قيمة.

النتائج استكشافية ولا تثبت علاقة سببية أو دلالة دينية.
