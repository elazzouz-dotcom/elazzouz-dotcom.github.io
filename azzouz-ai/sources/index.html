Note: This is a link directory, not an automatic integration. No static list can contain every external source. Listing a service does not mean Azzouz AI is connected to it. GitHub Pages does not provide a server-side database; never put API secrets or credentials in public client code. Check terms, licenses, privacy, and rate limits before connecting or downloading data.

عن الربط · About integrations

للبحث الآلي، يلزم API موثقة تسمح بالاستخدام المناسب وCORS أو وسيط خادمي آمن. للبيانات الخاصة أو مفاتيح API استخدم backend أو Worker مع مصادقة وصلاحيات محدودة. التخزين الكبير يتطلب ميزانية وفهرسة ونسخًا احتياطيًا وسياسة حذف.

Automated search requires a documented API with appropriate usage permission and CORS, or a secure server-side proxy. Private data and API keys require a backend or Worker with authentication and least-privilege access. Large-scale storage requires budgeting, indexing, backups, and deletion policies.
