مصادر الويب والبيانات والتخزين

كتالوج واسع ومنظم لمواقع البحث، المعرفة المفتوحة، الأبحاث، البيانات العامة، الأرشيفات، والمستودعات السحابية. اضغط على رابط المصدر لفتحه أو مراجعة توثيقه الرسمي.

تنبيه: لا يمكن حصر «كل» المواقع أو قواعد البيانات في قائمة ثابتة؛ هذا دليل منتقى لمصادر معروفة وروابطها الرسمية. إدراج المصدر هنا لا يعني أن Azzouz AI متصل به أو يتحقق من كل محتواه. GitHub Pages موقع ثابت ولا يوفّر قاعدة بيانات خادمية. لا تُرسل بيانات حساسة ولا تضع مفاتيح API في JavaScript العام. قبل الربط أو تنزيل البيانات، راجع الترخيص، شروط الاستخدام، الخصوصية، حدود الطلبات، وإمكانية CORS. البحث الآلي في التطبيق يظل محدودًا بالمصادر المفعّلة فيه وبموافقتك.

ماذا تعني إضافة المصدر إلى الموقع؟

  • رابط في الدليليفتح موقع المزود أو توثيقه فقط، ولا يرسل سؤال المستخدم.
  • بحث آلي من المتصفحيتطلب API عامة مناسبة، CORS، التزامًا بالحدود، والتحقق من النتائج والروابط.
  • قاعدة خاصة أو مفتاح سريتتطلب خدمة خلفية ومصادقة وتحديد صلاحيات؛ لا تضع الأسرار في صفحة GitHub Pages.
  • قاعدة معرفة ضخمةتتطلب بنية تخزين وفهرسة ونسخًا احتياطيًا وتكلفة تشغيل وسياسة حذف وخصوصية؛ لا توجد سعة غير محدودة مجانية.

هذا كتالوج روابط منتقى وليس تكاملًا آليًا شاملًا. افحص التراخيص وشروط الاستخدام قبل جمع البيانات أو إعادة نشرها، ولا تحمّل قواعد بيانات كاملة دون إذن وخطة مناسبة.
