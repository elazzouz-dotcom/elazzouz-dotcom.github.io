متطلبات الربط · Integration requirements

GitHub Pages وحده لا يخزن البيانات مركزيًا. لربط قاعدة بيانات، أنشئ backend أو Worker، استخدم مصادقة وتحديد صلاحيات، أخفِ الأسرار، ووفّر سياسات نسخ احتياطي وحذف ومراقبة تكلفة.

GitHub Pages alone cannot centrally store data. To connect a database, deploy a backend or Worker, authenticate users, apply least privilege, protect secrets, and define backups, deletion, and cost monitoring.
