

## ضوابط الخصوصية بعد المراجعة
- طلبات المصادر لا تبدأ إلا بعد الموافقة والبحث اليدوي. لكل طلب AbortController محفوظ في الجلسة؛ سحب الموافقة يرسل إشارة إلغاء للاتصالات الجارية ويمنع العاملين من إطلاق بقية المصادر. لا يمكن استرجاع طلب قد استلمه المزود بالفعل، ولا تُحفظ النتائج الجزئية الموقوفة في ذاكرة Azzouz.
- موافقة التعرف الصوتي منفصلة عن موافقة إخراج الصوت. سحب موافقة الميكروفون يوقف جلسة التعرف ويتجاهل أي نص يصل بعدها. إخراج الكلام لا يحدث لأسئلة الكتابة، ويمكن سحب موافقته أثناء النطق لإلغاء `speechSynthesis`; قد يستخدم محرك الجهاز خدمة محلية أو شبكية.
- روابط النتائج والذاكرة تطابق المضيف المحدد حرفيًا لكل مصدر، ولا تُقبل المضيفات الفرعية أو مخططات غير HTTPS.


## واجهات المصادر والتحقق

حُصرت استدعاءات التطبيق في خمس واجهات قراءة عامة، بعد مراجعة وثائقها الرسمية واختبار استجابات عامة وCORS في 2026-11-04. لا يرسل التطبيق مفاتيح أو بيانات حساب، ويعرض النتائج كمقتطفات مرتبطة بالمصدر لا كإجابة مولدة:

| المصدر | واجهة البحث المسموحة | توثيق المزود | ملاحظة الاستخدام |
| --- | --- | --- | --- |
| AlQuran Cloud | `https://api.alquran.cloud/v1/search/{query}/all/{edition}` | [API](https://alquran.cloud/api) | مطابقة نصية للآيات أو الترجمة؛ استجابة 404 موثقة لعدم وجود تطابق تُعرض كصفر نتائج، لا كخطأ عام. لا تفسير أو فتوى. |
| Wikipedia / MediaWiki | `https://{ar,en}.wikipedia.org/w/api.php?action=query&list=search...&origin=*` | [API:Search](https://www.mediawiki.org/wiki/API:Search) | اختيار نطاق اللغة من السؤال، و`origin=*` لطلبات CORS؛ المقتطفات قصيرة ورابط المقال الأصلي ظاهر. |
| OpenAlex | `https://api.openalex.org/works` | [Searching](https://help.openalex.org/api/searching/) | بيانات فهرسة علمية؛ الملخص والفهرسة قد لا يتوفران أو لا يكونان كاملين. |
| Crossref | `https://api.crossref.org/v1/works` | [REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) | بيانات ببليوغرافية وDOI؛ لا تُقدَّم كدليل علمي مستقل ولا يُفترض توفر الملخص. |
| GitHub | `https://api.github.com/search/repositories` | [Search repositories](https://docs.github.com/en/rest/search/search#search-repositories) | مستودعات عامة ووصف أصحابها؛ ليس مصدرًا علميًا عامًا. الطلبات بلا اعتماد، لذا تخضع لحدود GitHub العامة. |
| DuckDuckGo | رابط يدوي إلى `https://duckduckgo.com/?q=...` | لم تُفعّل API في الصفحة | عُطّل الاستدعاء الآلي لـInstant Answer لأن توثيقه/عقده الحالي لم يُتحقق منه بما يكفي؛ لا يُرسل السؤال إلا إذا نقر الزائر الرابط اليدوي. |

تحدد النواة ثلاث نتائج كحد أقصى لكل مزود، ومهلة 10 ثوانٍ لكل طلب، وتحدد الواجهة خمسة أسئلة بحث خارجي في الدقيقة داخل الجلسة. هذا حاجز استخدام محلي وليس ضمانًا لحصة المزود؛ تظهر أخطاء المصدر منفردة ولا يُعرض على أنها نجاح. تُزال وسوم HTML من المقتطفات قبل عرضها، وتُقبل روابط HTTPS من مضيف محدد حرفيًا لكل مصدر فقط.

لا يوجد اتصال بنموذج لغوي أو محرك تصفح شامل في هذه الصفحة. التحويل الحسابي المحلي محصور في محلل تعبيرات مسموحة، لا `eval` أو `Function`. نتائج البحث قد تكون ناقصة أو متقادمة؛ يجب فتح المرجع الأصلي والتحقق منه. دعم التعرف الصوتي يعتمد على المتصفح وقد يرسل الصوت إلى مزوده بعد موافقة الزائر؛ الكتابة بديل دائم.
