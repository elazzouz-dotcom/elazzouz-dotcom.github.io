اربط GitHub وGoogle بأمان

مركز إعداد للتكاملات. لا تُحفظ كلمات المرور أو مفاتيح API داخل الموقع أو مستودع GitHub. الاتصال الفعلي يحتاج OAuth وخادم Callback آمن.

الخدمات المتاحة

ابدأ من لوحة المطور الرسمية، ثم ضع Client ID في الخادم فقط. لا تضع Client Secret في JavaScript أو GitHub Pages.

GH

GitHub

يحتاج إعداد OAuth

الوصول إلى المستودعات، الملفات، الفروع، وطلبات السحب بعد موافقة المستخدم.

  • النطاق المقترح: repo للمستودعات الخاصة أو صلاحيات القراءة للمستودعات العامة.
  • Callback يجب أن يكون على خادم HTTPS، وليس GitHub Pages مباشرةً.
فتح GitHub Developer Settings ↗دليل OAuth
G

Google

يحتاج إعداد OAuth

الوصول الاختياري إلى Drive وDocs وSheets بعد موافقة المستخدم وبأقل صلاحيات ممكنة.

  • فعّل APIs المطلوبة فقط من Google Cloud Console.
  • استخدم OAuth consent screen وقيّد المستخدمين المسموح لهم في وضع الاختبار.
فتح Google Cloud Credentials ↗دليل OAuth

عنوان Callback المقترح

ضع هذا العنوان في إعداد OAuth بعد نشر خادم المصادقة. لا يمكن تنفيذ تبادل Client Secret داخل صفحة GitHub Pages الثابتة.

https://YOUR-BACKEND.example.com/oauth/callback

أفضل بنية: GitHub Pages للواجهة + Cloudflare Worker أو n8n أو خادم Node.js خاص لتبادل الرموز وتخزينها مشفرة.
