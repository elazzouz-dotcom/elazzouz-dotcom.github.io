حل مشاكل ربط حساب TikTok

دليل عملي خطوة بخطوة لربط الحساب عبر OAuth الرسمي فقط. هذه الصفحة لا تطلب كلمة مرور TikTok ولا تجمع العملات ولا تشغّل أي تفاعل آلي.

قبل البدء: الربط لا يعمل إذا كان التطبيق غير منشور أو كان حسابك غير مضاف إلى Test users في وضع Sandbox.

الخطوات الأساسية

1

افتح TikTok for Developers

سجّل الدخول بالحساب المالك للتطبيق، ثم افتح التطبيق الذي يحتوي على Login Kit.

فتح TikTok Developers
2

فعّل Login Kit للويب

من Products أو Login Kit اختر Web، وتأكد أن Web Redirect URI مضاف حرفيًا.

3

أضف الصلاحية المطلوبة

فعّل user.info.basic فقط عند الحاجة لمعلومات الحساب العامة. لا تستخدم صلاحيات غير ضرورية.

4

في Sandbox أضف حسابك إلى Test users

أضف اسم حساب TikTok الذي سيجرب الربط، ثم وافق على الدعوة من حساب TikTok نفسه.

5

ابدأ الربط من Azzouz

افتح Hunter أو صفحة الاستوديو واضغط «ربط حساب TikTok». وافق من صفحة TikTok، ثم انتظر الرجوع إلى الموقع.

تشخيص محلي للرابط

رسائل الخطأ الشائعة وحلها

Unsupported provider أو Provider is not enabled

هذه الرسالة تخص مزود مصادقة غير مفعّل في خدمة المصادقة، وليست خطأ في كلمة مرور TikTok. فعّل المزود الصحيح أو استخدم Login Kit الرسمي الخاص بـ TikTok.

Redirect URI mismatch

انسخ الرابط من صفحة التطبيق كما هو. لا تضف شرطة مائلة في النهاية إذا لم تكن موجودة، ولا تستخدم رابطًا مختلفًا بين localhost والموقع العام.

App is in Sandbox / user not authorized

أضف الحساب إلى Test users، وافتح الدعوة من حساب TikTok نفسه. لا يمكن للكود تجاوز قيود Sandbox.

تعاد الصفحة إلى الموقع دون حساب مربوط

امسح جلسة الربط القديمة، أعد فتح الموقع، وتأكد من السماح بالنوافذ وإكمال الموافقة. إذا استمر الخطأ، راجع Client Key وRedirect URI وسجل الخطأ الظاهر.

هل يستطيع الموقع جمع صناديق LIVE أو العملات تلقائيًا؟

لا. TikTok لا يوفّر هنا API عموميًا لجمع صناديق LIVE أو العملات، والأداة مخصصة للتتبع اليدوي والربط الرسمي للمعلومات العامة فقط.
