تنبيه أمان: احمِ مفتاح API

لا تشارك مفتاح API في المحادثات أو صفحات الويب العامة. خزّنه في إعدادات بيئة محلية آمنة، ولا تضعه في كود الواجهة أو مستودع عام. لا تحتاج إلى Project ID للبدء وفق هذا الدليل.

ابدأ دون إعداد محلي

جرّب أول جلسة في Playground

الجلسة تشغيل واحد لمتصفح سحابي. يتيح Playground تجربة أمثلة جاهزة ومشاهدة المتصفح أثناء عمله دون تثبيت أدوات على جهازك.

  1. افتح Playground وسجّل الدخول إلى حسابك.
  2. شغّل أحد الأمثلة الجاهزة من محرر الشيفرة.
  3. راقب المتصفح عبر Live View، ثم أوقف الجلسة عند الانتهاء.
  4. افتح تفاصيل الجلسة لمراجعة التسجيل والسجلات.

اختر نوع المهمة
