انشر موقعك الحالي دون أن تغيّر بنيته.

هذا المشروع صفحات HTML وCSS وJavaScript، وليس تطبيق React أو Vite. انشر الملفات الموجودة كما هي؛ لا تستبدل الصفحة الرئيسية بقالب React ولا تضف ملفات بناء لا يحتاجها الموقع.

الاختيار المناسب

الموقع الثابت الحالي يكفيه GitHub Pages.

للحفاظ على الروابط التي تبدأ من جذر الموقع مثل /tools وملفات المشاركة مثل /theme.css، انشره كموقع حساب مستخدم، وضع الملفات في جذر المستودع المخصص لحسابك.

خطوات النشر

ارفع الملفات الحالية ثم فعّل Pages.

لا تنشئ تطبيق React جديدًا ولا تحذف المجلدات الموجودة.

  1. ١

    أنشئ مستودع الحساب

    أنشئ مستودعًا عامًا بالاسم USERNAME.github.io، مع استبدال USERNAME باسم حساب GitHub الخاص بك. اختر main كفرع أساسي. هذا هو إعداد User Site المناسب للمسارات المطلقة الحالية التي تبدأ بـ /.

  2. ٢

    ارفع المشروع كاملًا إلى الجذر

    ارفع index.html وtheme.css وlanguage.js وجميع مجلدات الصفحات. يجب أن يكون ملف الصفحة الرئيسية في جذر المستودع، لا داخل مجلد إضافي. اجعل المستودع عامًا إذا أردت النشر المجاني المعتاد على GitHub Pages، وتأكد أن الملفات نفسها موجودة في جذر فرع main.

    index.html
/theme.css
/language.js
/tools/index.html
/contact/index.html
/github-pages/index.html

    ارفع الملفات باستخدام Git

    من مجلد المشروع المحلي، استبدل <repository-remote> بعنوان المستودع الذي أنشأته على GitHub. لا ترفع مجلدًا أبًا يحتوي الموقع داخل مجلد فرعي؛ ارفع محتويات الموقع إلى جذر المستودع.

    cd path/to/your/project
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <repository-remote>
git push -u origin main

    أو ارفع من واجهة GitHub

    1. افتح المستودع، ثم اختر إضافة ملف ورفع الملفات.
    2. اسحب محتويات مجلد الموقع، بما فيها مجلدات الصفحات والملفات المشتركة، إلى منطقة الرفع.
    3. أكمل حفظ الملفات على فرع main، وتحقق أن index.html ظاهر في جذر المستودع.
  3. ٣

    فعّل النشر من إعدادات Pages

    في إعدادات المستودع، افتح Pages، واختر النشر من فرع main ومجلد الجذر /(root)، ثم احفظ الإعداد.

  4. ٤

    تحقق من الموقع المنشور

    انتظر اكتمال عملية النشر التي يعرضها GitHub، ثم افتح عنوان الموقع الذي يظهر في إعدادات Pages. اختبر الصفحة الرئيسية وصفحات مثل الأدوات والتواصل، وتأكد من تحميل CSS وJavaScript.

حافظ على مشروعك

ما الذي لا ينبغي استبداله؟

  • لا تستبدل index.html الحالي بقالب يحتوي على <div id="root">؛ ذلك القالب مخصص لتطبيق React منفصل.
  • لا تضف package.json أو vite.config.js لهذا الموقع الثابت لمجرد نشره على Pages؛ لا يحتاج بناء React.
  • احتفظ ببنية كل صفحة داخل مجلدها، مثل tools/index.html، وأبقِ ملفات الأصول المشتركة في الجذر كما هي.
  • GitHub Pages يستضيف ملفات ثابتة فقط. النماذج التي تتطلب API أو خادمًا، مثل مسارات /api/leads، تحتاج خدمة خلفية منفصلة.

قبل النشر

قائمة تحقق قصيرة

  • الصفحة الرئيسية index.html في جذر المستودع.
  • كل مجلد صفحة يحتوي ملفه index.html.
  • ملفات theme.css وlanguage.js مرفوعة مع المشروع.
  • لا توجد مفاتيح API أو أسرار ضمن الملفات المنشورة.
