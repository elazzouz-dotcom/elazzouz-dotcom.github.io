كيف يتم الربط الحقيقي؟

الجهاز أو المحطة الأرضية يرسل حالة الاتصال إلى بوابة تملكها أنت، ثم تحفظ Cloudflare KV آخر حالة وتعرضها هذه الصفحة. لا تضع مفاتيح المودم أو رموز المزود في GitHub Pages. مسار الإدخال المحمي هو /satellite/ingest، ويحتاج سرًا منفصلًا باسم SATELLITE_INGEST_TOKEN.

POST /satellite/ingest
Authorization: Bearer <gateway-token>
{"providers":[{"id":"starlink","status":"online","signal":86}]}

تنبيه: ظهور «تجريبي» يعني عدم وجود مودم فضائي متصل بعد. لا تعرض اللوحة سرعة أو إشارة وهمية. هذه اللوحة منشورة داخل مختبر شبكة SemVer في العقدة N-600.
