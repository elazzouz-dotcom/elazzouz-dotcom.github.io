استوديو التحضير

النشر يحتاج خطوة استضافة فعلية

لا يمكن لهذه الصفحة رفع الموقع أو تفعيل عنوان منشور نيابةً عنك.

ما الذي تفعله هذه الصفحة؟

تعرض صفحات الموقع، وتساعدك على متابعة قائمة تجهيز النشر، وتحفظ تقدم القائمة وملاحظاتك محليًا في المتصفح.

ما الذي لا تفعله؟

لا ترفع الملفات، ولا تنشئ استضافة أو نطاقًا، ولا تضمن أن الموقع أصبح متاحًا للزوار. أكمل عملية النشر من أداة الاستضافة التي تستخدمها.

الخصوصية

لا تدخل أسرارًا

قائمة التحقق والملاحظات تُحفظ في تخزين هذا المتصفح فقط. تجنب كتابة مفاتيح API أو بيانات اعتماد أو معلومات حساسة.

GitHub Workbench

تعديل ونشر الكود من Hosting Studio

سجّل الدخول عبر GitHub Device Flow، ثم حمّل أي ملف من مستودعك وعدّله واحفظه كـ commit. يبقى Access Token في ذاكرة الصفحة فقط ولا يُحفظ في localStorage.

غير متصل

للنشر على GitHub Pages: احفظ ملف index.html في الفرع الرئيسي، ثم فعّل Pages من إعدادات المستودع إذا لم تكن مفعّلة. لا تضع Client Secret أو مفاتيح API داخل الملفات.
