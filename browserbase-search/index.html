Browserbase · Search API

جهّز طلب البحث بالطريقة التي تناسبك.

أنشئ مثالًا بصيغة cURL أو JavaScript أو Python. لا تُرسل هذه الصفحة الطلب ولا تطلب مفتاح API؛ يقرأ كل مثال المفتاح من متغير البيئة عند تشغيله.

إعداد محلي

خيارات البحث

يُضبط العدد محليًا بين 1 و100. راجع حدود الخدمة الحالية قبل تنفيذ الطلب.

يتطلب مثال Python مكتبة requests. إذا لم تكن مثبتة في بيئتك، ثبّتها وفق إرشادات مشروعك.

حماية المفتاح

لا تلصق مفتاحك في الصفحة أو في الشيفرة الناتجة. عيّن BROWSERBASE_API_KEY في بيئتك المحلية، ولا تشارك سجلات الطرفية أو الاستجابات الحساسة.
