React Router example

Loader and product component

In a configured React Router app, params.pid comes from the route segment (for example, products/:pid). Replace getProduct with your real data source.

import { Route } from "./+types/product";

export async function loader({ params }: Route.LoaderArgs) {
  const product = await getProduct(params.pid);
  return { product };
}

export default function Product({ loaderData }: Route.ComponentProps) {
  return <div>{loaderData.product.name}</div>;
}

Note: this static-site preview uses sample products in your browser. It demonstrates the loader-to-component data flow but does not run React Router or load data from a server.

React Router configuration

Enable the Vite Environment API

Place this in react-router.config.ts in a configured React Router project. It enables the v8 Vite Environment API future flag; it does not run in this static-site preview by itself.

import type { Config } from "@react-router/dev/config";

export default {
  future: {
    v8_viteEnvironmentApi: true,
  },
} satisfies Config;

Corrected example

Server-side React Router action

For a real HTTP response with status 201 and a custom header, run this in a configured React Router application with a real createItem implementation. The comma after headers is required.

import { data } from "react-router";

export async function action({ request }: Route.ActionArgs) {
  const formData = await request.formData();
  const item = await createItem(formData);

  return data(item, {
    headers: { "X-Custom-Header": "value" },
    status: 201,
  });
}

Important: this static-site demo mirrors the form-to-result flow only. It cannot run a React Router server action or create an actual HTTP 201 response.
