اختيار الخدمة

اختر بين التجربة السريعة والبنية المخصصة.

قد تكون مهام الاستدلال كثيفة الحسابات، لذلك يمكن تشغيلها على خادم بدلًا من الجهاز المحلي. توفّر Hugging Face أكثر من طريقة للاتصال بالنماذج المستضافة:

للتجربة والنماذج الأولية

Inference API

تشغّل الاستدلال على بنية Hugging Face، وتساعدك على تجربة النماذج وبناء نموذج أولي بسرعة. قد تختلف الإتاحة والحصة المجانية وفق الحساب وشروط الخدمة الحالية؛ راجع التفاصيل قبل الاستخدام.

للنشر والإنتاج

Inference Endpoints

تنشر نموذجًا على بنية مخصصة ومدارة، ضمن بيئة سحابية تختارها. بعد النشر تحصل على عنوان نقطة نهاية تتصل به من تطبيقك.

ما وظيفة InferenceClient؟ إنها مكتبة Python ترسل طلبات HTTP إلى خدمة الاستدلال نيابةً عنك. إذا أردت إرسال الطلبات مباشرة باستخدام cURL أو Postman، فراجع توثيق الخدمة. تتوفر أيضًا مكتبة JavaScript لتطبيقات الويب.

البدء السريع

أنشئ صورة من وصف نصي

هذا مثال Python يستخدم InferenceClient لإنشاء صورة وحفظها على جهازك.

from huggingface_hub import InferenceClient

client = InferenceClient()

image = client.text_to_image("An astronaut riding a horse on the moon.")
image.save("astronaut.png")

يختار العميل افتراضيًا نموذجًا مقترحًا للمهمة، وهنا هي تحويل النص إلى صورة. النتيجة كائن صورة من مكتبة PIL، ويمكن حفظه كملف.

تنبيه: لا تعرض الواجهة كل خيارات كل نموذج. راجع توثيق المعاملات التفصيلية وبطاقة النموذج لمعرفة المدخلات والخيارات المتاحة.

النماذج ونقاط النهاية

حدّد نموذجًا بعينه أو استخدم عنوان نقطة نهاية.

يمكنك تحديد النموذج عند إنشاء العميل، أو تمريره إلى استدعاء المهمة. إذا نشرت نموذجًا عبر Inference Endpoints، مرّر عنوان نقطة النهاية بدل معرّف النموذج.

from huggingface_hub import InferenceClient

# حدّد النموذج عند إنشاء العميل
client = InferenceClient(model="prompthero/openjourney-v4")
image = client.text_to_image("A quiet mountain lake at sunrise.")

# أو مرّر النموذج إلى استدعاء المهمة
client = InferenceClient()
image = client.text_to_image(
    "A quiet mountain lake at sunrise.",
    model="prompthero/openjourney-v4",
)

# استخدم عنوان نقطة النهاية المنشورة لديك
endpoint_client = InferenceClient(model=ENDPOINT_URL)
image = endpoint_client.text_to_image("A quiet mountain lake at sunrise.")

ENDPOINT_URL اسم متغير توضيحي؛ استبدله بعنوان نقطة النهاية الخاصة بك أو اقرأه من متغير بيئة. لا تضع عنوانًا خاصًا أو رمز وصول في صفحة عامة. بعد اختيار نموذج، ثبّت معرّفه لتقليل تغيّر النتائج، وتأكد من توافقه مع المهمة.

المصادقة

احتفظ برمز الوصول في بيئة موثوقة.

يمكن لـInferenceClient استخدام رمز Hugging Face المحفوظ عند تسجيل الدخول محليًا. ويمكنك تمرير الرمز صراحةً عند الحاجة. بعض الاستخدامات قد تسمح بطلب غير موثّق، لكن المصادقة تمنح الحساب حصة أعلى بحسب الشروط الحالية، وهي ضرورية للوصول إلى النماذج الخاصة أو نقاط النهاية الخاصة.

import os
from huggingface_hub import InferenceClient

client = InferenceClient(token=os.environ["HF_TOKEN"])
الأمان: لا تلصق الرمز في هذه الصفحة أو في واجهة عامة أو مستودع منشور. خزّنه في إعدادات بيئة محلية أو على الخادم، واستخدم صلاحيات مناسبة.

العميل غير المتزامن

استخدم AsyncInferenceClient مع asyncio.

توجد نسخة غير متزامنة من العميل تعتمد على aiohttp. ثبّت الاعتمادية الإضافية أو حزمة inference، ثم نفّذ الاستدعاءات داخل سياق asyncio.

pip install --upgrade "huggingface_hub[inference]"
# أو: pip install aiohttp
import asyncio
from huggingface_hub import AsyncInferenceClient

async def main():
    client = AsyncInferenceClient()

    image = await client.text_to_image(
        "An astronaut riding a horse on the moon."
    )
    image.save("astronaut.png")

    async for token in await client.text_generation(
        "The Hugging Face Hub is",
        stream=True,
    ):
        print(token, end="")

asyncio.run(main())

قد تعيد بعض المهام تدفقًا من النتائج. راجع توثيق Python الرسمي لاستخدام asyncio، وتحقق من نوع النتيجة الذي تعيده المهمة قبل معالجة التدفق.

نصائح متقدمة

خطط للمهل الزمنية والمدخلات الثنائية.

المهلة الزمنية

قد يستغرق تحميل النموذج أو تنفيذ الاستدلال وقتًا. يقبل العميل قيمة timeout بالثواني؛ وإذا انتهت المهلة يرفع InferenceTimeoutError. اختر مدة مناسبة وتعامل مع الاستثناء.

المدخلات الثنائية

يمكن لبعض المهام استقبال بايتات، أو ملف مفتوح للقراءة الثنائية، أو مسار ملف محلي، أو عنوان URL. قد ينزّل العميل الملف من العنوان قبل إرساله إلى خدمة الاستدلال.

from huggingface_hub import InferenceClient, InferenceTimeoutError

client = InferenceClient(timeout=30)

try:
    image = client.text_to_image("A small cabin in a snowy forest.")
except InferenceTimeoutError:
    print("لم يكتمل طلب الاستدلال خلال المهلة المحددة.")
قبل الاستخدام: راجع أحدث التوثيق وبطاقة النموذج لمعرفة المعاملات المدعومة والتوافق والتكاليف والحدود. قد تتغير هذه التفاصيل.
