For example mode, list each .c or .cpp file that contains its own main() function. For demo mode, list all source files in the application.

The supplied command description says test mode is suited to CGAL's developer testsuite, but does not specify its exact generated contents. This starter uses standard CTest scaffolding and leaves test targets for you to define.

What this page can and cannot do

A web page cannot discover files in your current terminal directory. Enter source file names here, then save the generated text as CMakeLists.txt in your project folder. This is an independent starter generator, not the official cgal_create_cmake_script command.
