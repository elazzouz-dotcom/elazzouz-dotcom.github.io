خوارزمية آية الدين

محاكاة تعليمية مستوحاة من خطوات البقرة 282: الإدخال، الكتابة، الكاتب، الشهود، الاستثناء، القياس، والحالة الخاصة.

﴿ يَا أَيُّهَا الَّذِينَ آمَنُوا إِذَا تَدَايَنتُم بِدَيْنٍ إِلَىٰ أَجَلٍ مُّسَمًّى فَاكْتُبُوهُ ... ﴾

هذا نموذج تعليمي لفهم البنية المنطقية للنص، وليس عقدًا ماليًا أو فتوى أو بديلًا عن استشارة قانونية.

INPUT · الإدخال

1 · WRITE

اكتبوا الدين إلى أجله.

بانتظار الإدخال

2 · WRITER

كاتب يكتب بالعدل.

بانتظار الإدخال

3 · LOOP / الشهود

شاهدان، أو رجل وامرأتان عند الحاجة.

بانتظار الإدخال

4 · EXCEPTION

لا يأب الكاتب ولا الشهداء، مع تسجيل الرفض كاستثناء.

بانتظار الإدخال

5 · SCALABILITY

الدين الصغير والكبير يمران بالمنهج نفسه.

بانتظار الإدخال

6 · EDGE CASE

التجارة الحاضرة تخفف الكتابة، مع بقاء الإشهاد عند البيع.

بانتظار الإدخال

OUTPUT · النتيجة

شغّل الخوارزمية لرؤية المسار.

معايير الجودة المحاكاة: أقسط = عدل أكثر · أقوم للشهادة = دقة أكثر · أدنى للريب = شك أقل.
